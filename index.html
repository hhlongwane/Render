GETTING STARTED · 5 MIN

Welcome to CloudForge

This guide walks through the demo workflow. CloudForge here is a front-end sample: it does not connect to your Git provider or provision real cloud resources.

1. Open the dashboard

Use the Get started button to open your local workspace. The sample dashboard includes example services and deployment events.

2. Create a service

Choose New service, give it a name, and select a service type. The app stores this demo state in your browser.

Service type: Web Service
Runtime: Node
Branch: main
Deploy mode: Simulated

3. Explore the activity

Use the Deploy button to add a sample event to the deployment history. Nothing is sent to a cloud provider.

Demo notice: do not enter secrets, passwords, API keys, or sensitive production data.
