# CloudForge

An original, responsive cloud-platform website inspired by the public developer experience of modern application hosting services. This project is independent and is not affiliated with Render.com.

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## Included

- Responsive marketing homepage and product pages
- Interactive pricing comparison with monthly/yearly display toggle
- Searchable quickstart documentation
- Filterable template gallery
- Dashboard with sample services, deployment history, simulated logs, and settings
- Create-service modal, demo deploy/pause/resume controls, and local browser persistence
- Accessible navigation, keyboard dismissible modal, mobile layout, and status messages

## Important limitations

This is a static front-end demo. Deployments, authentication, billing, databases, logs, and cloud infrastructure are simulated in the browser. It does not connect to Git providers, provision real services, execute builds, or charge payments. Connect a real backend and cloud provider before using a platform like this for production workloads.
